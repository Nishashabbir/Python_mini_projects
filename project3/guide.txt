 MOST IMPORTANT LINE OF ENTIRE PROGRAM
label.after(1000, time)
THIS is the heart of live updating.
 WHAT IS .after() ?
Means:
 “Run something later after some milliseconds”
 Syntax
widget.after(delay, function)
 HERE:
1000
means:
1000 milliseconds = 1 second
 SO THIS MEANS:
label.after(1000, time)
 “After 1 second, run time() again”
 THIS CREATES AN INFINITE UPDATE LOOP
Flow:
time()
   ↓
update label
   ↓
wait 1 second
   ↓
time()
   ↓
update label
   ↓
wait 1 second
forever.
 THIS IS EXTREMELY IMPORTANT
The clock is NOT updating automatically magically.
YOU manually told tkinter:
run this function again and again
using .after().
 VERY IMPORTANT THINKING
This is a type of:
scheduled callback
Used everywhere:
clocks
animations
games
notifications
auto-refresh systems
live dashboards

Note: //////////////////////////////////////////
Tkinter Layout Managers

Tkinter has multiple systems to place widgets:

Method	Purpose
.pack()	simple layout
.grid()	row/column layout
.place()	exact x/y position
 YOU MUST USE ONE OF THEM

Without:

.pack()
.grid()
or .place()

 widget stays invisible.
